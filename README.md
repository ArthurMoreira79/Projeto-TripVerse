# TripVerse

Site de uma agência de viagens fictícia, com roteiros guiados para grupos pequenos. Acesse o link abaixo para dar uma olhada!

https://projeto-tripverse.vercel.app/

## O que tem na página

- **Hero** com vídeo de fundo e chamada direta para os roteiros.
- **Roteiros mais procurados**: cada bloco aumenta ao passar o mouse e abre um painel lateral com os detalhes do destino (duração sugerida, melhor época, descrição e destaques).
- **Avaliações** de clientes (fictícias) que já viajaram com a agência.
- **Paisagens**: galeria de fotos e vídeos enviados por quem já viajou. Os vídeos tocam ao passar o mouse no computador ou ao tocar na tela no celular.
- **Rodapé** com contato e crédito de quem criou o site.

## Tecnologias

HTML, CSS e JavaScript puro, sem frameworks ou build step.

## Estrutura de imagens

- `imagens/tours/` — fotos dos roteiros
- `imagens/testemunhas/` — fotos dos clientes nas avaliações
- `imagens/landscapes/` — fotos e vídeos da galeria de paisagens (com os posters dos vídeos em `imagens/landscapes/posters/`)
- `imagens/tripverse-marca.png` — marca usada como favicon e no hero
